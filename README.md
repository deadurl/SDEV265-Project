# SDEV265-Project
Personal Budget &amp; Expense Tracker - log income/expenses, categorize spending, and view simple summaries or charts.
An app where users log income/expenses, categorize spending, and view simple summaries or charts. Could include budget goals, recurring expense tracking, or alerts when a category goes over budget. Good for a team that wants a well-understood domain with room to add complexity (charts, categories, multi-user accounts) if they want a bigger challenge.


# Running the files
Once downloaded, navigate to the SDEV-Project exe located in build and run. Once running, open browser and navigate to localhost:18080.
